# Rental Housing Law Navigator

MIT AI Hackathon x RealPage (participant pack v5). Pick any sample building and see which
housing rules apply on a given date, every answer traced to the exact sentence of law.

**Not legal advice.** Outputs are a prototype built from a fixed public corpus.

> Status: phase 0 scaffold. Pipeline stages land phase by phase; unbuilt stages exit with
> "not implemented yet". Evaluation numbers will be generated by `eval`, never typed here.

## Run

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -e ".[dev,llm]"

python -m navigator --help     # or: make <target>   /   ./run.ps1 <target>
python -m pytest -q            # tests
python -m pytest -q -m smoke   # fail-closed smoke tests (no network, no LLM)
```

Pipeline order: `ingest > extract > verify > geocode > lookups > changes` (`all` runs them).

## Layout

| Path | What |
|---|---|
| `CLAUDE.md` | working rules (read first) |
| `docs/CONTRACT.md` | exact formats and data facts; wins over the plans |
| `BACKEND_PLAN.md`, `FRONTEND_PLAN.md` | build plans |
| `NOTES.md` | decisions and open questions |
| `data/starter/` | the participant pack, read-only (checksummed) |
| `navigator/` | pipeline, engine and API (Python) |
| `eval/` | self-evaluation harness and team-verified gold set |
| `outputs/` | `rules.json`, `lookups.json`, `changes.json` + intermediates |
| `web/` | frontend |
